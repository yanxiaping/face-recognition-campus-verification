# 基于微信小程序的入校人脸识别验证系统

一个基于微信小程序、Flask 和 PyTorch 的人脸识别入校验证系统。

## 项目简介

本项目用于模拟校园入校场景下的人脸身份验证。用户通过微信小程序调用摄像头进行人脸采集，图片上传至后端后进行人脸检测、特征提取和身份匹配，并返回识别结果。

在基础人脸识别功能之外，项目还增加了识别历史记录、日志保存、Excel 导出以及自动休眠/唤醒等功能，并针对页面切换时识别流程中断的问题进行了调试和修复。

## 技术栈

- 微信小程序
- JavaScript / WXML / WXSS
- Python
- Flask
- PyTorch
- MTCNN
- InceptionResnetV1
- JSON / NPY 文件存储

## 系统功能

### 人脸识别

通过微信小程序摄像头采集人脸图像，上传至 Flask 后端。

后端使用 MTCNN 进行人脸检测与对齐，再使用 InceptionResnetV1 提取人脸特征，通过欧氏距离进行特征比对，完成身份验证。

### 识别历史记录

系统会保存识别结果和相关信息，微信小程序端可以查看历史识别记录。

为了避免一次加载过多数据影响页面运行，前端主要展示最近的识别记录，后端保存完整日志。

### 日志与 Excel 导出

识别完成后将相关信息保存到本地 JSON 日志文件中，并提供数据导出功能，可以将历史识别记录导出为 Excel 表格。

### 自动休眠与唤醒

当连续多次未检测到人脸时，系统自动进入休眠状态，减少摄像头持续运行带来的资源消耗。

点击屏幕后可以重新唤醒并恢复人脸识别流程。

### 页面切换问题修复

开发过程中发现，从人脸识别页面切换到历史记录页面后再返回，可能出现识别流程异常的问题。

排查后发现原识别定时器没有及时销毁，页面重新显示后产生定时器冲突。

针对这一问题，在页面隐藏时使用 `onHide` 清理定时器并重置相关状态，在页面重新显示时通过 `onShow` 重新初始化识别流程，解决页面切换后的识别异常。
